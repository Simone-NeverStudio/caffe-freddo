# Caffè Freddo

Versione web del libro *Caffè Freddo – Storia di una rinascita* (monologhi + player per le canzoni).

## Pubblicazione su GitHub Pages
1. Carica tutto il contenuto di questa cartella nel repository `caffe-freddo` (Add file → Upload files).
2. Metti i 4 mp3 nella cartella `audio/` con i nomi indicati in `audio/LEGGIMI.txt`.
3. Settings → Pages → Source: *Deploy from a branch* → branch `main`, cartella `/ (root)` → Save.
4. Dopo 1-2 minuti il sito è su `https://<utente>.github.io/caffe-freddo/`.
